# CloudShell

A full-stack web application providing browser-based Linux terminal emulation with Role-Based Access Control (RBAC) and state snapshot capabilities.

## Features

### Core Features

- **Emulated Terminal** - Interactive Linux-like terminal supporting commands: `ls`, `cd`, `cat`, `echo`, `pwd`, `mkdir`, `touch`, `rm`, `env`, `export`, `whoami`, `date`, `help`, `clear`
- **Role-Based Access Control** - Three roles with granular permissions:
  - `admin` - Full system access (manage users, terminals, snapshots)
  - `operator` - Manage own resources (create/execute terminals, create/restore snapshots)
  - `viewer` - Read-only access
- **State Snapshots** - Save and restore terminal state including filesystem, environment variables, and working directory
- **User Management** - Create, update, and delete users with role assignments

2. **Terminal Emulator Engine** - The terminal emulator (`src/backend/src/services/terminalEmulator.ts`) uses a state machine approach:

   - Command parser with argument handling
   - Environment variable interpolation
   - Path resolution and normalization

3. **CI/CD Pipeline** - Automated GitHub Actions workflow generated by AI:

4. **10xDevs Skills** - Custom Claude Code skills for consistent development:
   - `cloudshell-terminal-cmd` - Adding new terminal commands
   - `cloudshell-rbac` - Managing permissions and roles
   - `cloudshell-test` - Writing tests following project patterns

## Getting Started

### Prerequisites

- Node.js 22+
- Docker & Docker Compose
- PostgreSQL (or use Docker)

### Installation

1. Start infrastructure:
```bash
cd docker && docker-compose up -d
```

2. Install dependencies:
```bash
cd src && npm install
```

3. Setup database:
```bash
cd src/backend
npm run db:migrate
npm run db:seed
```

4. Start development servers:
```bash
# Terminal 1 - Backend
cd src/backend && npm run dev

# Terminal 2 - Frontend
cd src/frontend && npm run dev
```

## API Endpoints

### Authentication
- `POST /api/auth/login` - Login and receive JWT token
- `POST /api/auth/register` - Register new user (admin only)
- `GET /api/auth/me` - Get current user info

### Terminals
- `GET /api/terminals` - List all terminals
- `POST /api/terminals` - Create new terminal
- `POST /api/terminals/:id/execute` - Execute command
- `DELETE /api/terminals/:id` - Delete terminal

### Snapshots
- `GET /api/snapshots` - List all snapshots
- `POST /api/snapshots` - Create snapshot from terminal
- `POST /api/snapshots/:id/restore` - Restore snapshot to terminal
- `DELETE /api/snapshots/:id` - Delete snapshot

### Users & Roles (Admin only)
- `GET /api/users` - List all users
- `POST /api/users` - Create user
- `GET /api/roles` - List all roles with permissions
